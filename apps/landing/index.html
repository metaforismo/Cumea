Before you clone it.

Where does Cumea run?

On a desktop or a VM you administer. The Expo app is a paired control surface for that host, not a second runtime.

Which models can I use?

The picker is multi-provider. Today that includes Claude Agent, Grok/Gemini ACP, Codex app-server, and Box cloud agent. Tools, handoffs, and computer use are mounted only when that CLI actually supports them.

Does the host need to stay online?

Yes. Routines and remote control continue only while the Cumea harness and its configured provider stay running on a machine you control.

Can I download a signed macOS app?

Not yet. v0.1.0 is a source-only developer preview. There is no signed or notarized macOS download.

What does this page’s demo do?

It is an interactive illustration in your browser. It does not start a Cumea host, call a model, touch your mail, or persist what you type.

Source first, for now.

There is no signed and notarized macOS download yet. The current release is for developers building from source.
