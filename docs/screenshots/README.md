# Screenshot provenance

The screenshots in this directory are first-party Cumea captures made with synthetic demo data.
They contain no customer data and do not embed screenshots or assets from Grok Bot, OpenMausBot,
Rakazo, or other products.

- Desktop images were captured from the local Cumea web/Electron interface at 1440 x 960.
- Mobile images were captured from the native Expo development build on an iPhone 17 Pro simulator
  running iOS 26.5. Simulator evidence is not physical-device acceptance.
- The fixture does not claim that a live third-party provider, Box VM, or external app completed the
  displayed work.
